注意事項・使い方
  • 水温の絶対値ではなく、分布と境目（フロント）を見る道具です。MUR SST は夜間観測主体の解析値のため、日中の実測水温とは数度ずれることがあります。
  • 本マップは漁場を保証するものではありません。あくまで参考情報であり、出航判断は利用者ご自身の責任で行ってください。
  • データは1日1回自動更新。観測日が数日前のまま止まっている場合は更新エラーの可能性があります。
  • PC の QGIS では data/latest/sst.tif（COG）を HTTP レイヤとして直接開けます。
