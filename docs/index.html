注意事項・使い方
  • 水温の絶対値ではなく、分布と境目（フロント）を見る道具です。MUR SST は夜間観測主体の解析値のため、日中の実測水温とは数度ずれることがあります。
  • 本マップは漁場を保証するものではありません。あくまで参考情報であり、出航判断は利用者ご自身の責任で行ってください。
  • 海面をタップすると、その地点の数値が出ます。
  • 色の切替: 「フロントを探す」はその日の水温幅でコントラスト最大化、「変化を追う」は季節固定の色なので昨日との比較ができます。
  • 「フロント」レイヤは水温の境目の強さ (℃/km)。暖水と冷水の境目には回遊魚が集まりやすいとされます。
  • 岸から2〜3km以内は陸地の熱の影響を受けるため参考値です。特に閉鎖性水域（別府湾奥・守江湾内）の値は信頼性が低くなります。薄く表示されている部分は推定誤差が大きい海域です。
  • ◀ ▶ ボタンで過去のデータ（約90日分）を見られます。
  • PC の QGIS では data/latest/sst.tif / front.tif（COG）を HTTP レイヤとして直接開けます。
  • 参考: 大分県 海況・魚群速報
